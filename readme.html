BRICK RUSH 99

完整遊戲指南與系統解析

1 基本操作與連線對戰

🕹️ 鍵盤與觸控操作

  • 單人模式：使用 ← → 方向鍵移動擋板。
  • 單機雙人：1P 使用 A D 鍵；2P 使用 ← → 方向鍵。
  • 觸控設備：畫面左右兩側會自動顯示虛擬按鈕。

🌐 線上連線建房

點擊主畫面的「連線對戰」，你可以：

  • 建立房間：輸入自訂名稱後點擊建立，系統會產生一組專屬的 房間代碼。
  • 加入房間：輸入代碼後即可加入你的大廳。
  • 連線機制：支援最多 99 人同時遊玩的大亂鬥淘汰賽！
2 基本模式

每關結束後會有 10 秒極限搶答，每 10 關會出現Boss。

  • 單人遊戲關卡結束時，系統會利用你收集到的符號生成一道數學題，你有 10 秒鐘可以作答。答對將獲得 +25% HP 回復與 +500 積分！
  • 雙人對戰在單機雙人模式中，計時3分鐘，能量集滿可向對方發動隨機攻擊。關卡結束，將觸發雙方搶答環節。1P 使用 1-4 鍵，2P 使用 7-0 鍵，率先答對者可獲得巨額獎勵。
  • 多人連線多人模式為淘汱制，不是比分數，存活到最後者獲勝，能量集滿可向隨機對手發動技能攻擊。
3 化學 DLC 模式

開啟此模式後，磚塊將化為週期表上的化學元素。

🧪 元素收集與稀有度

擊破帶有英文字母的方塊即可將化學元素收入背包。

  • 四大基礎元素 (H, C, N, O) 掉落率最高。
  • 重金屬與放射性元素需存活到高層數關卡才會逐漸解禁。
  • 在商店中將心儀技能加入願望清單 (★)，可強制提高特定稀有元素的掉落機率。

⚔️ 技能定位

超過 100 種真實存在的化學分子，將賦予你強大的能力：

防禦 (H2O)：回復HP與護盾 攻擊 (NH3)：全場毒霧腐蝕 控制 (CO2)：敵方擋板減速

高等級的放射性分子 (如 PuO2) 甚至能引發毀滅性的全場核爆。

4 商店與裝備系統

🎒 技能解鎖與裝備

  • 解鎖：點擊未解鎖的卡片，消耗對應的元素或點數來獲取該技能。
  • 升級：對已解鎖的技能再次點擊，可消耗加倍的資源提升等級，大幅增強威力並延長持續時間。
  • 裝備：點擊畫面上方的 + 號空槽位，接著點選已解鎖的技能即可裝備。(單人支援 5 槽，多人為 3 槽)
  • 使用：已裝備的技能在遊戲中若有足夠的元素，會自動使用技能。雙人/多人模式中有攻擊對手的技能可選用。

♻️ 單人：轉換爐機制

在單人模式中，元素是唯一的貨幣。

  • 如果你急需某種稀有元素，可以在左側的「轉換爐」投入多餘的元素。
  • 系統會依據投入的總原子量，隨機等價轉換出其他元素。
  • 注意：質量過低可能會導致轉換失敗，材料直接蒸發！
  • 關卡之間的配方商店是提升戰力的唯一途徑

💰 多人連線：點數經濟

為了確保競技的公平性與流暢度，多人連線模式關閉了複雜的轉換爐，改採「競技點數 (PT)」制。

  • 你在對戰中打碎方塊獲得的分數，將等比轉換為商店點數。
  • 你可以使用點數直接購買缺失的元素。
  • 也可以將背包中用不到的元素出售變現，換取點數來解鎖更強大的殺傷技能。
  • 雙人/多人只有在開局前能進商店購買技能。
